# Production Audit — Work Message 6: Wave 1 Batch 03

**Status:** Authored draft; internal structural review completed; not independently reviewed or learner-validated.

## Scope delivered

Six assignable learning units, one for each Wave 1 discipline: MATH, ENG, ELEC, RES, LANG and COMM. The batch is approximately 4,100 words and includes a companion machine-readable assignment registry.

## Unit coverage

| Code | Discipline | Learning focus | Required evidence |
|---|---|---|---|
| MATH-MOD-015 | MATH | Mathematical modelling and validation | Model report and validation table |
| ENG-SWE-002 | ENG | Git/version control workflow | Repository history, diff and test evidence |
| ELEC-MEAS-002 | ELEC | Safe low-voltage measurement and uncertainty | Annotated schematic and measurement record |
| RES-METHOD-002 | RES | Research question and study design | Research protocol and bias/ethics register |
| LANG-ACQ-002 | LANG | Deliberate language acquisition | Study plan, performance and delayed transfer task |
| COMM-PRES-002 | COMM | Oral presentation and Q&A | Presentation artefact and evaluation |

## Internal checks performed

- Six unique unit codes; no duplicate code within this batch.
- Each unit contains purpose, prerequisites, outcomes, conceptual model, concepts, worked example, guided and independent practice, answer guidance, misconceptions, assessment, evidence, retention and progression.
- Electronics unit has explicit low-voltage safety boundary and treats unsafe meter connection as a hard failure.
- Research unit distinguishes descriptive/observational/experimental claims and includes ethics and privacy constraints.
- Language unit separates receptive and productive competence and requires delayed transfer.
- Communication unit scores substance and delivery separately and requires honest handling of uncertainty.
- Assignment registry parses as JSON and maps all six units to the same source pack.
- The prior 18-discipline taxonomy and wave allocation are preserved.

## Known limitations and outstanding gates

- No independent expert review has occurred.
- No learner pilot, accessibility review or reading-level calibration has occurred.
- Resource links and licensing are not yet verified against each objective.
- The importer has not been run against the companion registry in the actual ATHENA application.
- The unit drafts need later cross-reference reconciliation against canonical micro-skill IDs and prerequisite graph edges.

## Decision

Keep all six units in `IN_PROGRESS`. This batch increases instructional depth across Wave 1; it does not complete any of the six disciplines.
