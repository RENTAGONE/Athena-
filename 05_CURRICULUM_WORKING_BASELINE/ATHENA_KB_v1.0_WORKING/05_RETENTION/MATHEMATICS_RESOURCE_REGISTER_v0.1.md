# Mathematics Resource Register — Initial Verified Scope Sources v0.1

**Status:** Initial high-level source verification only. Individual lesson-to-section alignment and ongoing availability checks remain open.

1. **OpenStax, Algebra and Trigonometry 2e** — https://openstax.org/books/algebra-and-trigonometry-2e/pages/preface
   - Scope verified from the publisher's preface: prerequisites; equations and inequalities; functions; linear functions; polynomial and rational functions; exponential and logarithmic functions; unit circle; periodic functions; trigonometric identities/equations; applications; systems; analytic geometry; sequences, probability and counting.
   - Appropriate as a free, structured secondary/introductory college-level reference for algebra and trigonometry. It is not a complete source for all of statistics, calculus, number theory or advanced linear algebra.
2. **OpenStax, College Algebra 2e** — https://openstax.org/details/books/college-algebra-2e
   - Use for functions, polynomial/rational functions, exponential/logarithmic functions, systems and analytic geometry.
3. **Khan Academy Mathematics** — https://www.khanacademy.org/math
   - Use as a guided practice and video-explanation supplement. Match specific lessons to objectives rather than citing the platform generically as proof of coverage.
4. **3Blue1Brown, Essence of Linear Algebra** — https://www.3blue1brown.com/topics/linear-algebra
   - Visual intuition supplement; not a substitute for formal definitions, proofs and exercises.
5. **MIT OpenCourseWare Mathematics** — https://ocw.mit.edu/search/?d=Mathematics
   - Advanced course materials; select by prerequisite level and verify syllabus, assignments and solution availability.

## Source-use rules
- Cite exact chapter/section when a lesson relies on a source-specific definition or method.
- Prefer primary educational publishers, university materials and open textbooks.
- Record edition, licence, access date and any adaptation restrictions before embedding substantial excerpts.
- Do not reproduce textbook passages; author original explanations and cite sources for factual/technical grounding.
