## How to use this register
- Start with the linked resource only after checking the module objective and learner prerequisites.
- Use more than one source for consequential claims; distinguish original evidence, interpretation and instructional explanation.
- Record which exact claim or skill the resource supports. Do not treat a whole website as authoritative for every subject.
- Resource exposure is not evidence of learning. Learner explanation, application and independently assessed work remain required.
- Local law, tax, financial products, safety standards and public-health details must be checked against applicable Bangladesh sources before operational use.
- Paid or registration-gated resources are optional alternatives, never mandatory where a free pathway is available.

## Important limitations and unresolved coverage
- 30 resource records cover all 18 disciplines, but the corpus is an initial seed, not an exhaustive or balanced bibliography.
- 161/216 baseline modules have candidate source links; 55 have no candidate link in this batch. Even linked modules may need more specific or locally applicable resources.
- ENG, WORK, ART, INDEP, BODY and CYBER have visible module-level gaps; see the machine-readable 216-row crosswalk for exact module IDs.
- The current resource schema accepts canonical `ATH-*` linked object IDs but not the working baseline `BASE-*` module IDs. This batch preserves schema validity by linking resources to discipline IDs and placing module links in a separate crosswalk. A future schema decision must not silently expand the canonical ID policy.
- US/UK government sources are educational references, not Bangladesh legal or regulatory guidance.
- The Berklee voice course is paid; its inclusion records scope, not a requirement to purchase it.
- No expert review, learner pilot, resource licensing audit, local Bangladesh resource review or curriculum approval is claimed.
