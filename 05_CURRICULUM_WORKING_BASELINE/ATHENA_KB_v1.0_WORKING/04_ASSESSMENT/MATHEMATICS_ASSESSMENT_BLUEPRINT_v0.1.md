# ATHENA Mathematics — Assessment Blueprint v0.1

**Status:** Working specification; item bank authoring and psychometric validation remain open.

## Assessment layers

1. **Entry diagnostic:** untimed or low-stakes adaptive sampling across number sense, operations, fractions/ratio, algebra, geometry, graphs, probability/data and reasoning. It identifies prerequisites; it is not a permanent label.
2. **Formative checks:** short retrieval, explain-why, error diagnosis and worked problems embedded within each unit. Feedback names the misconception and requires a fresh attempt.
3. **Unit mastery checks:** mixed item types with explicit scoring and critical-error rules. A correct numerical answer without required reasoning may receive partial credit only.
4. **Cumulative checkpoints:** interleave older and newer skills to detect forgetting and method-selection problems.
5. **Practical modelling tasks:** collect or interpret data, define variables/units, state assumptions, calculate, check plausibility and communicate limitations.
6. **Transfer tasks:** solve a structurally related problem in a different context without being told which mathematical method applies.

## Evidence dimensions

- Conceptual understanding: explains what an object or operation means.
- Procedural accuracy: executes a valid method with correct notation and arithmetic.
- Strategic selection: chooses an appropriate representation or method.
- Reasoning and justification: explains why steps preserve truth and identifies counterexamples where relevant.
- Modelling: translates context into mathematics and interprets results back in context.
- Communication: uses symbols, units, diagrams and prose unambiguously.
- Calibration: identifies assumptions, uncertainty and limits rather than overstating certainty.

## Scoring rules

Use analytic rubrics with task-specific criteria. Do not use a universal pass percentage as a proxy for competence across all mathematics. Set unit thresholds after reviewing item difficulty and critical outcomes. A learner may demonstrate a skill through an alternate valid method. Calculation slips should be distinguished from conceptual errors; an invalid method that happens to produce the right answer is not full evidence.

## Item bank requirements

For each high-priority objective, author at least: one retrieval prompt, one conceptual discrimination item, two worked-problem variants, one error-diagnosis item, one contextual application and one transfer item. Include varied numbers and contexts; avoid reusing only one surface pattern. Every answer key must show reasoning, accepted alternatives and common incorrect reasoning.

## Integrity and accessibility

Allow appropriate tools when the target is modelling or interpretation; require unaided work only when unaided fluency is itself the target. State calculator policy, time constraints, units, rounding rules and permitted references. Avoid culturally narrow contexts and inaccessible visual-only questions. Provide text descriptions for diagrams and equivalent accessible formats.

## Validation still required

Subject-matter review, item ambiguity review, learner think-alouds, difficulty calibration, reliability analysis where sample sizes permit, bias review, and alignment audit against the actual learning objectives.
