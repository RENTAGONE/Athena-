# Legacy Micro-skill Practice Protocols — Batch 02

**Status:** Draft protocols for safe learning design; not certification.

## Doomsday Algorithm
1. Learn the Gregorian calendar scope and leap-year rule (divisible by 4, except century years unless divisible by 400).
2. Learn the weekday anchor method in small pieces; write each intermediate value while learning.
3. Practise dates in one century, then vary years and months.
4. Add leap-year and century-boundary cases only after ordinary cases are stable.
5. Test 20 unseen dates; mark answer correctness and explanation separately.
6. Delayed test on another day without reviewing the method immediately beforehand.
**Common errors:** forgetting century exceptions; mixing month codes; arithmetic slips; applying Gregorian rules to a different calendar.

## Visual Observation (formerly “Visual Profiling”)
1. Observe a neutral image for a fixed short interval.
2. Write only directly visible facts: objects, positions, colours, actions and spatial relationships.
3. Separate observations from inferences and assign confidence.
4. Recheck the image and count unsupported assumptions.
5. Repeat with a scene containing more objects or motion.
**Assessment:** high factual coverage with very few unsupported inferences. Never infer personality, intent, sensitive traits or criminality from appearance.

## Memory Palace
1. Select a familiar, stable route with distinct loci.
2. Place one vivid but simple image at each locus.
3. Walk the route mentally in a consistent direction.
4. Retrieve forward, backward and after a delay.
5. Test a second list to identify interference.
**Assessment:** delayed ordered recall plus explanation of errors. The method does not validate the truth of remembered information.

## Lucid-dream reality checks (optional)
1. Keep sleep duration and regularity as the priority.
2. If desired, use a calm daytime reflection prompt such as “What was I doing just before this moment?”
3. Record dream recall briefly after waking only if it does not disrupt the morning.
4. Do not set alarms to interrupt sleep or force repeated night checks.
5. Stop if sleep, anxiety or sense of reality is negatively affected.
**Assessment:** reflective consistency and wellbeing, not a guaranteed lucid dream.

## Speed Reading
1. Record baseline reading rate and comprehension on an appropriate passage.
2. Identify the purpose: locate information, survey, or learn deeply.
3. Practise previewing headings and paragraph structure.
4. Use skimming only for overview; return to normal pace for difficult passages.
5. Test on equivalent passages and report words/minute and comprehension separately.
**Pass condition:** comprehension remains above the learner-set threshold; no reward for speed that sacrifices understanding.

## Morse Code
1. Learn a small group of letters by sound/rhythm rather than visual dot-dash memorisation alone.
2. Add letters gradually and practise mixed recognition.
3. Practise sending with consistent element and letter spacing.
4. Record speed and error rate; do not increase speed until accuracy is stable.
5. Use short distributed sessions and delayed receive/send tests.

## Rubik’s Cube 3×3
1. Learn cube notation and how turns change state.
2. Learn a beginner solution in stages, checking each stage before proceeding.
3. Use a scramble generator or a trusted physical scramble method; solve without step-by-step video.
4. Repeat on separate days to establish repeatability.
5. Only then explore more efficient methods or timed solves.
**Evidence:** valid complete solve, method explanation, cold repeat on a later day.

## Locksport — strict practice boundary
1. Learn the ethical/legal rule: only a transparent educational practice lock owned by the learner, with guardian approval.
2. Identify the visible parts and understand the basic mechanical vocabulary.
3. Keep the learning environment separate from real access systems.
4. Record the ethical boundary as part of the assessment.
**Not included:** covert entry, real-world lock bypass, defeating security, opening property without explicit ownership/permission, or evasion.

## French Drop
1. Learn the basic coin handling slowly with a soft, ordinary coin-sized prop.
2. Practise the receiving-hand concealment and natural attention direction without rushing.
3. Rehearse both hands and multiple viewing angles.
4. Perform only as a consensual magic effect.
5. Assess repeatability and naturalness, not ability to deceive in transactions.

## One-handed shuffle
1. Use a standard deck in good condition.
2. Learn comfortable grip and packet separation slowly.
3. Recombine without forcing the cards.
4. Build clean repetitions before speed.
5. Stop if pain or strain appears.

## Faro shuffle
1. Learn what an in-faro and out-faro mean conceptually.
2. Practise aligning the two packets evenly.
3. Interweave slowly with minimal force.
4. Count and inspect the result; distinguish a true faro from a loose imperfect shuffle.
5. Progress to repeatability before speed or stacked sequences.

## Coin rolling and pen spinning
1. Use a safe, lightweight object and a clear practice area.
2. Isolate the movement at low speed.
3. Use short sets with rests; avoid repetitive strain.
4. Count clean repetitions and drops.
5. Practise each hand separately and record asymmetry without forcing equal performance.

## Origami
1. Learn valley and mountain folds and accurate edge alignment.
2. Practise squash, reverse and petal folds using simple diagrams.
3. Complete one simple model with instructions.
4. Recreate it later from diagrams or memory.
5. Progress to more complex models only when folds remain accurate.

## Stadium whistle
1. Wash hands and practise in a setting where a loud whistle is appropriate.
2. Learn a comfortable hand/finger position without forcing the jaw or tongue.
3. Use brief attempts and rest between them.
4. Prioritise a clear signal over maximum loudness.
5. Stop if pain, irritation or dizziness occurs; avoid prolonged loud practice near ears or in enclosed spaces.

## Signature dish
1. Choose one accessible dish and document the exact ingredient list.
2. Prepare a mise en place checklist and identify allergens.
3. Practise measuring, timing, safe heat/knife handling and food hygiene with appropriate supervision.
4. Record taste, texture, doneness and timing after each attempt.
5. Repeat on separate occasions and adjust one variable at a time.
**Assessment:** three safe, consistent preparations with a reproducible recipe.

## Advanced everyday tie knots
1. Select a finite list of everyday/decorative knots.
2. Learn each knot's intended purpose and limitations.
3. Practise from memory using ordinary cord.
4. Inspect dressing and security for the intended low-risk use.
5. Explicitly reject use for climbing, rescue, rigging, restraint or life-safety loads.

## Ambidexterity Basics — continuous practice protocol
**This is not a weekend challenge and has no permanent completion checkbox.**
1. Baseline: note dominant hand and comfortable ability for each low-risk task.
2. Start with one task, such as brushing teeth, using the phone for simple navigation, or opening a normal door.
3. Practise slowly; prioritize control and comfort over speed.
4. Add another daily task only after the first is comfortable.
5. Reassess monthly or at a user-selected interval using matched tasks.
6. Keep a few tasks in ordinary use so the skill remains functional.
7. Optional later branches: handwriting, drawing, instrument technique or sport-specific bilateral skills.
**Never switch hands for hot/sharp tools, driving/road tasks, emergency actions or any activity where unfamiliarity increases risk. Stop if pain develops.**

## CPR/AED and choking response
ATHENA's role is to explain the importance of training, help locate appropriate recognised instruction, track course provenance and remind the learner of renewal requirements. Practical skills must be taught and assessed by qualified instructors using appropriate manikins and current local guidance. No text-only or AI-only certification.
