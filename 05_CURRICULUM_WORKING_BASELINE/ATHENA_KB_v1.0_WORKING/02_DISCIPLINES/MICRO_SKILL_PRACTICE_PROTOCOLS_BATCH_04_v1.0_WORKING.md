# ATHENA Micro-skill Practice Protocols — Batch 04
**Status:** Draft protocols; not certification or mastery awards.
**Scope:** Complete the remaining 44 records that previously lacked a protocol, including legacy choices and longitudinal ambidexterity.
**Safety:** Any safety-critical practical capability requires current qualified instruction and supervised assessment. Text completion is never certification.

## MS-P04-001 — Active recall from a blank page (MS-01-001)
**Capability category:** Cognitive & learning
**Target performance:** Reconstruct a topic outline without notes, then verify and correct omissions.
**Prerequisite and setup:** Confirm the learner has the required safe environment, appropriate materials and permission. Start with a baseline attempt and record what is already reliable. Do not increase speed or complexity until control is consistent.
**Acquisition sequence:**
1. **Observe and model:** Watch a correct demonstration or study a trusted step-by-step reference. Identify the critical movement/decision sequence and the most likely failure point.
2. **Isolate:** Practise the smallest controllable component slowly. Use short sets and pause when accuracy or safety declines.
3. **Assemble:** Combine components in the correct order. Use feedback after each attempt rather than repeating errors at speed.
4. **Vary:** Change one condition at a time—position, material, context, prompt or starting state—while preserving the core success criteria.
5. **Independent attempt:** Remove prompts and perform from a cold start. Record errors, time only when speed is relevant, and note any assistance.
**Practice dosage:** Use brief focused sessions with rest between attempts. Stop if pain, unsafe conditions, frustration-driven rushing or repeated loss of control appears. The number of hours is not a mastery criterion.
**Assessment:** Given a studied 1-page topic, produce an accurate outline covering its key ideas in 5 minutes. Add a second attempt on a different day and one varied-context test before marking the skill independently demonstrated.
**Common failure modes:** Rushing, copying visible motion without understanding the sequence, relying on immediate feedback, practising only one context, and mistaking a lucky success for repeatable performance.
**Retention check:** Test unaided after a delay selected for this skill's decay profile. If performance falls below the criterion, set `needs_revision`, preserve prior evidence, and schedule a focused relearning session.
**Transfer check:** Use the skill in a new but safe context. Record which parts transfer and which need adaptation.
**Maintenance profile:** D1. Do not assume annual-only refresh is sufficient; safety-critical items require qualified refresher practice.
**Evidence required:** unaided_performance, observed_or_recorded_result, delayed_retrieval_check.
**Safety / scope note:** Use safe, age-appropriate equipment and adult supervision where the activity or environment requires it.
**Status:** Protocol authored as draft; independent subject review and rubric calibration required.
