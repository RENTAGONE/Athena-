## MS-02-004 — Everyday knot tying

**Practice protocol:** Practise a small, defined set for ordinary non-load-bearing uses: square knot, bow, and simple stopper. Learn the intended use and failure modes of each. Work with soft cord on a table; dress each knot neatly; test only with light hand tension. Re-tie from memory on separate days and identify an incorrect or asymmetric structure. Never use these knots for climbing, rescue, suspension, restraints or life-safety loads.

**Independent test:** Perform the target task without step-by-step prompting in a fresh example; record accuracy, time only where relevant, support used and any safety constraint.

**Delayed retention:** Repeat after a meaningful delay without reviewing the instructions immediately beforehand. If performance falls below the agreed standard, record `needs_revision` and schedule a targeted refresher; preserve the previous evidence.

**Transfer:** Repeat in a different but equivalent context, material, prompt or environment to check whether the skill generalises.
