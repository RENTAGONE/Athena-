## Expansion requirements

- Give each skill an observable performance definition and context.
- Split compound skills where distinct assessment or retention profiles are needed.
- Define hard prerequisites only when failure without them is likely; use recommended/helpful links otherwise.
- Attach at least one retrieval check and one application/performance task to each active learning unit.
- Record safety constraints and age-appropriate practice conditions.
- Add resource records only after source verification; never invent URLs or credentials.
- Add transfer links only with an explicit mechanism and known limitations.
