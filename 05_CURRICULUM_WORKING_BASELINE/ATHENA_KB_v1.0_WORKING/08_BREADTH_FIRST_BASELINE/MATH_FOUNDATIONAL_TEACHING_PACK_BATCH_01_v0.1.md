# BASE-MATH-001 — Number sense, magnitude and estimation

**Suggested workload:** 2–3 focused sessions of 30–45 minutes  
**Entry knowledge:** Basic whole-number counting and familiarity with place value; decimals and negative values are introduced here.

**Learning outcomes**
- Read and compare whole numbers and decimals using place value.
- Estimate sums and products using sensible rounding.
- Use number lines, signed values and absolute value correctly.
- Check exact answers against estimates, units and context.


## What this module teaches

Number sense is the ability to understand what numbers represent, how large or small they are, how they relate to one another, and whether a result is plausible. It is not just fast mental arithmetic. It is the habit of checking scale before trusting a calculation.

A number has a value determined by its position and context. In base ten, each place is ten times the place to its right: in 4,582, the 4 represents four thousands, the 5 five hundreds, the 8 eight tens and the 2 two ones. Decimal places continue the pattern in the other direction: tenths, hundredths, thousandths. This positional structure lets us estimate by rounding and compare quantities without calculating every detail.

A number line represents order and distance. Moving right means increasing value; moving left means decreasing value. Zero is a reference point, not a number that makes all values positive. The distance from zero is absolute value: both −5 and 5 are five units from zero, although they represent different positions.

## Worked example 1 — Estimate before calculating

A shop sells 3 notebooks at ৳47 each and 2 pens at ৳18 each. An exact total is 3 × 47 + 2 × 18 = 141 + 36 = ৳177.

Before calculating, round ৳47 to ৳50 and ৳18 to ৳20. The estimate is 3 × 50 + 2 × 20 = ৳190. The exact answer, ৳177, is plausible because it is close to the estimate. An answer such as ৳1,770 would signal a likely place-value or multiplication error.

## Worked example 2 — Check magnitude with units

A person walks 1.2 km. Since 1 km = 1,000 m, the distance is 1,200 m, not 120 m or 12,000 m. The conversion factor changes the unit but not the physical distance. Writing the unit beside every value makes a factor-of-ten error easier to catch.

## Guided practice

1. Estimate 198 + 403 + 52 by rounding each value to a convenient number. Then calculate exactly and compare.
2. Place −3, 0, 2.5 and 4 on a number line. Which is farthest from zero? Which is greatest?
3. A 750 mL bottle is described as 0.75 L. Explain why these represent the same volume.

**Guided answers:** (1) Estimate about 200 + 400 + 50 = 650; exact total 653. (2) Greatest is 4; farthest from zero is 4 because its absolute value is 4. (3) One litre is 1,000 mL, so 750 mL ÷ 1,000 = 0.75 L.

## Independent exercise set

1. Estimate 49 × 21 without exact multiplication. Then calculate exactly.
2. A trip is 2.4 km. Express it in metres and justify the decimal movement.
3. Which is larger: 0.7 or 0.65? Explain using place value or equivalent hundredths.
4. A calculator displays 0.0036 for a task expected to produce a value near 36. Give two possible classes of error to investigate.
5. Create a realistic situation where −8 is meaningful and explain what zero represents.

**Answer guidance:** (1) Estimate 50 × 20 = 1,000; exact 1,029. (2) 2,400 m. (3) 0.70 > 0.65. (4) Check unit conversion, decimal placement, input scale and formula. (5) Accept contexts such as temperature below zero or account balance below a zero-balance reference; the reference must be stated.

## Common errors and feedback

- **Treating a calculator display as automatically correct:** check input, operation, units and order of magnitude.
- **Comparing decimals by digit count:** write 0.7 as 0.70 before comparing with 0.65.
- **Rounding too early:** retain exact values during multi-step calculations when precision matters; estimate separately as a check.
- **Confusing absolute value with signed value:** |−5| = 5, but −5 is still less than zero.

## Assessment

Given a short receipt, a distance conversion and a signed-temperature scenario, estimate each result first, calculate exactly, show units, and identify any implausible result. **Independent standard:** all three results are correctly scaled; estimates are reasonable; units are consistent; the learner explains at least one error check without relying on a calculator display alone.

## Transfer task

Compare two mobile-data plans with different data quantities and prices. Estimate cost per gigabyte before calculating exactly. State the assumptions (same validity period, no hidden fees, usable data quantity) and explain when the cheaper unit price might still be the worse choice.

## Entry assumptions and next step

Entry: basic counting and familiarity with whole numbers; decimals can be introduced here. Next: arithmetic operations and fraction/decimal fluency. This module does not teach formal statistics or measurement uncertainty in depth.

# BASE-MATH-002 — Arithmetic operations and operation sense

**Suggested workload:** 2–3 focused sessions of 30–45 minutes  
**Entry knowledge:** BASE-MATH-001 or equivalent familiarity with place value and whole-number quantities.

**Learning outcomes**
- Choose operations from relationships rather than keywords.
- Interpret multiplication and division as equal groups, scaling and partitioning.
- Evaluate expressions using grouping and operation-priority conventions.
- Check results using inverse operations, estimation and units.


## What this module teaches

The four basic operations describe relationships between quantities. Addition combines amounts or finds a total. Subtraction finds a difference, a remaining amount or an unknown addend. Multiplication represents equal groups, scaling or a rectangular array. Division partitions a quantity into equal groups or asks how many groups of a given size fit.

The meaning of a problem should determine the operation. Keyword matching is unreliable: “more” does not always mean addition, and “per” does not always mean multiplication. Draw a bar model, table or equation when the relationship is unclear.

The order of operations is a convention that makes expressions unambiguous. Evaluate grouping symbols first, then exponents, then multiplication and division from left to right, then addition and subtraction from left to right. Multiplication does not automatically come before division; they share priority. Addition and subtraction also share priority.

Inverse operations help check work. Addition and subtraction reverse each other; multiplication and division reverse each other when division is defined. A check should test the original relationship, not merely repeat the same calculation.

## Worked example 1 — Model a multi-step purchase

A learner buys 4 pens at ৳12 each and pays with ৳100. The cost is 4 × 12 = ৳48. The change is 100 − 48 = ৳52. The model is “payment minus total cost”, not 100 + 48. Check: ৳48 + ৳52 = ৳100.

## Worked example 2 — Respect operation order

Evaluate 24 ÷ 3 × 2. Division and multiplication have equal priority, so work left to right: 24 ÷ 3 = 8, then 8 × 2 = 16. It is not 24 ÷ (3 × 2), which would be 4. Parentheses change the structure and must be shown when intended.

## Worked example 3 — Division as grouping

Thirty-six biscuits are packed into bags of six. The number of bags is 36 ÷ 6 = 6. If six children share 36 biscuits equally, each child receives 6. The calculation is the same, but the question being answered differs: number of groups versus amount per group.

## Guided practice

1. A 5-person group pays ৳350 equally. Write the division and state what the quotient means.
2. A tank contains 80 L. It loses 7 L each hour for 4 hours. Model the remaining quantity.
3. Evaluate 18 − 6 ÷ 3 + 2 × 4, showing the order.

**Guided answers:** (1) 350 ÷ 5 = ৳70 per person. (2) 80 − (7 × 4) = 52 L. (3) 18 − 2 + 8 = 24.

## Independent exercise set

1. A pack contains 8 cards. How many cards are in 7 packs? Show a second way to check.
2. A 96 cm ribbon is cut into 8 equal pieces. Find each length and explain the unit.
3. A person has ৳500, spends ৳135 and then receives ৳60. Write one expression and find the final amount.
4. Evaluate 48 ÷ 6 × 3 and compare it with 48 ÷ (6 × 3). Explain why they differ.
5. Create one real situation for 72 ÷ 9 where the answer means (a) number of groups and (b) amount per group.

**Answer guidance:** (1) 56 cards; repeated addition or 56 ÷ 7 = 8. (2) 12 cm per piece. (3) 500 − 135 + 60 = ৳425. (4) First is 24; second is 8/3; parentheses change the divisor. (5) Any two clearly distinguished sharing/grouping contexts.

## Common errors and feedback

- **Applying operations from keywords:** draw the quantities and relationship first.
- **Doing addition before multiplication:** follow the shared priority and left-to-right rule.
- **Ignoring units:** a quotient may be taka per person, centimetres per piece or bags—not just a bare number.
- **Checking by repeating the same steps:** use an inverse relationship or substitute into the original context.

## Assessment

Solve a multi-step shopping and sharing problem. Show a model or expression, explain each operation, preserve units and verify the result using an inverse operation or total reconstruction. **Independent standard:** operation choices match the relationships, order of operations is correct, and the check returns to the original quantity.

## Transfer task

A small digital-products seller buys 6 units at one price and sells them at another. Calculate total cost, revenue and gross difference for a stated quantity. Keep purchase cost per unit, selling price per unit and total amounts distinct; do not confuse gross difference with net profit after fees or other costs.

## Entry assumptions and next step

Entry: place value, whole-number and decimal familiarity. Next: fractions, decimals and proportional quantities. This module does not cover signed arithmetic or algebraic proof in depth.

# BASE-MATH-003 — Fractions, decimals and equivalent quantities

**Suggested workload:** 3–4 focused sessions of 35–50 minutes  
**Entry knowledge:** BASE-MATH-001 and BASE-MATH-002, including multiplication, division and place value.

**Learning outcomes**
- Represent the same quantity as a fraction, decimal and percentage where appropriate.
- Generate and simplify equivalent fractions.
- Add, subtract, multiply and divide fractions with non-zero denominators.
- Compare fractional and decimal quantities and explain the unit-size reasoning.


## What this module teaches

A fraction represents a number of equal parts relative to a whole or a unit. In a/b, the denominator b tells how many equal parts make one whole; the numerator a tells how many of those parts are being considered. The denominator cannot be zero. A fraction is also a division statement: a/b means a divided by b.

Equivalent fractions name the same quantity. Multiplying or dividing the numerator and denominator by the same non-zero number preserves the value because it multiplies or divides by one. For example, 1/2 = 2/4 = 50/100. The pieces look different, but the total quantity is unchanged.

Decimals are another base-ten representation of fractions with denominators such as 10, 100 or 1,000. For example, 0.35 means 35 hundredths, so 0.35 = 35/100 = 7/20. Percent means “per hundred”, so 35% = 35/100 = 0.35.

To add or subtract fractions, the parts must be expressed in a common unit size. To multiply fractions, multiply numerators and denominators; the result can often be simplified. To divide by a non-zero fraction, multiply by its reciprocal. These procedures make sense when interpreted as scaling or measuring quantities, not as arbitrary symbol tricks.

## Worked example 1 — Equivalent fractions

Simplify 18/24. Both 18 and 24 are divisible by 6, so 18/24 = 3/4. The value has not changed: both fractions represent three quarters. A visual check would divide the same whole into 24 parts and shade 18, or divide it into 4 parts and shade 3.

## Worked example 2 — Add unlike denominators

Calculate 1/3 + 1/4. Thirds and quarters are different-sized pieces, so add only after converting to a common size. The least common denominator is 12: 1/3 = 4/12 and 1/4 = 3/12. Therefore 4/12 + 3/12 = 7/12.

## Worked example 3 — Fraction to decimal

Convert 3/8 to a decimal by division: 3 ÷ 8 = 0.375. Check: 0.375 × 8 = 3. As a percentage, 0.375 × 100% = 37.5%.

## Guided practice

1. Write 2/5 as an equivalent fraction with denominator 100, then as a decimal and percentage.
2. Compare 5/8 and 3/4 by converting them to a common denominator.
3. Calculate 2/3 + 1/6 and explain why the denominators are not simply added.

**Guided answers:** (1) 40/100 = 0.4 = 40%. (2) 5/8 = 10/16 and 3/4 = 12/16, so 3/4 is larger. (3) 4/6 + 1/6 = 5/6; the denominator names the shared part size.

## Independent exercise set

1. Simplify 21/35 and explain the common factor used.
2. Calculate 3/4 − 2/5.
3. Calculate 2/3 × 3/5 and simplify.
4. A 2.4 L drink is poured equally into 6 bottles. How much is in each bottle? Give litres and millilitres.
5. Explain why 0.8 is greater than 0.75 even though 75 has more digits than 8.

**Answer guidance:** (1) 3/5 by dividing by 7. (2) 15/20 − 8/20 = 7/20. (3) 6/15 = 2/5. (4) 0.4 L = 400 mL. (5) Write 0.8 as 0.80; 80 hundredths exceeds 75 hundredths.

## Worked example 4 — Divide by a fraction

Calculate `3/4 ÷ 1/2`. Ask how many halves fit into three quarters. Since one half is two quarters, one whole contains two halves; three quarters contain one and a half halves. Symbolically, divide by a non-zero fraction by multiplying by its reciprocal: `3/4 × 2/1 = 6/4 = 3/2 = 1.5`. Check by multiplication: `3/2 × 1/2 = 3/4`.

**Additional independent practice:** Calculate `2/3 ÷ 4/5`. Explain why multiplying by `5/4` is valid, then check by multiplying your quotient by `4/5`.

**Answer:** `2/3 × 5/4 = 10/12 = 5/6`. Check: `5/6 × 4/5 = 20/30 = 2/3`.

## Common errors and feedback

- **Adding denominators:** this changes the size of the parts and is not valid; convert to a common denominator first.
- **Assuming a larger denominator means a larger fraction:** compare the actual values; for unit fractions, a larger denominator means smaller pieces.
- **Moving a decimal point without a reason:** use place value and division/multiplication by powers of ten.
- **Cancelling terms across addition:** cancellation is valid only for common factors of a numerator and denominator, not separate terms in a sum.

## Assessment

Complete a mixed task involving equivalence, comparison, addition/subtraction, decimal conversion and a contextual division problem. **Independent standard:** representations agree, operations preserve the meaning of the quantities, units are included, and the learner can explain at least one conversion rather than relying on a memorised rule.

## Transfer task

Scale a recipe from 4 servings to 6 servings. Express the scale factor as a fraction, calculate two ingredient quantities, and explain why each ingredient must be scaled consistently. Identify an ingredient where practical rounding may be needed and state the effect of that rounding.

## Entry assumptions and next step

Entry: whole-number division, multiplication and place value. Next: percentages, ratios and rates. Repeating decimals and formal rational-number proofs are outside this module’s introductory scope.

# BASE-MATH-004 — Percentages and proportional change

**Suggested workload:** 2–3 focused sessions of 35–50 minutes  
**Entry knowledge:** BASE-MATH-003, especially fraction-decimal equivalence and multiplication/division.

**Learning outcomes**
- Interpret percentages as rates per hundred and identify the base quantity.
- Calculate percentage amounts, increases, decreases and reverse percentages.
- Distinguish percentage points from relative percentage change.
- Model successive percentage changes multiplicatively and explain the result.


## What this module teaches

A percentage is a rate per hundred. The expression 18% means 18 out of every 100, or 0.18 as a decimal. To find p% of a quantity Q, calculate (p/100) × Q. Always identify the base quantity: “20% of what?” Without the base, a percentage statement is incomplete.

A percentage increase or decrease uses the original amount as the base unless the problem states otherwise. Increasing by 15% means multiplying by 1.15; decreasing by 15% means multiplying by 0.85. These multipliers combine the original 100% with the change. Repeated percentage changes are multiplicative, not simple addition of percentage labels.

A percentage point is the arithmetic difference between two percentages. If a rate rises from 20% to 25%, it rises by 5 percentage points. Relative to the original 20%, the increase is 5/20 = 25%. These statements describe different comparisons.

## Worked example 1 — Find a percentage of an amount

Find 15% of ৳800. Convert 15% to 0.15, then calculate 0.15 × 800 = ৳120. A mental check is 10% = ৳80 and 5% = ৳40; together they make ৳120.

## Worked example 2 — Discount and final price

A ৳1,200 item is discounted by 20%. The discount is 0.20 × 1,200 = ৳240. Final price = 1,200 − 240 = ৳960. Equivalently, pay 80% of the original: 0.80 × 1,200 = ৳960. The two methods should agree.

## Worked example 3 — Successive percentage changes

A price of ৳1,000 increases by 20%, becoming ৳1,200. It then decreases by 20% of the new price: 0.80 × 1,200 = ৳960. The final value is not ৳1,000 because the second 20% is calculated from ৳1,200, not the original ৳1,000.

## Worked example 4 — Reverse percentage

After a 20% discount, an item costs ৳960. The sale price is 80% of the original. Therefore original price = 960 ÷ 0.80 = ৳1,200. Do not add 20% of ৳960; the discount was 20% of the original price.

## Guided practice

1. Find 12% of ৳500 using 10% + 2%.
2. Increase 240 by 25% using a multiplier.
3. A value falls from 80 to 68. Find the percentage decrease.
4. A rate moves from 30% to 36%. State the percentage-point change and the relative percentage increase.

**Guided answers:** (1) ৳60. (2) 240 × 1.25 = 300. (3) Decrease 12; 12/80 = 0.15 = 15%. (4) 6 percentage points; 6/30 = 20% relative increase.

## Independent exercise set

1. Find 7.5% of ৳2,000.
2. A ৳1,600 item has a 12.5% discount. Find the discount and final price.
3. A quantity increases from 50 to 65. Find the percentage increase.
4. After a 10% reduction, a quantity is 450. Find the original quantity.
5. Explain why a 10% increase followed by a 10% decrease does not return to the starting value.

**Answer guidance:** (1) ৳150. (2) Discount ৳200; final ৳1,400. (3) Increase 15; 15/50 = 30%. (4) 450/0.9 = 500. (5) If the start is 100, increase gives 110; 10% of 110 is 11, so the result is 99.

## Common errors and feedback

- **Using the wrong base:** write the original amount beside the percentage before calculating.
- **Confusing percentage points with relative percent change:** state which comparison is being asked.
- **Adding successive percentages blindly:** use a multiplier for each change in sequence.
- **Reversing a discount incorrectly:** if the final is 80% of the original, divide by 0.80 to recover the original.

## Assessment

Solve a multi-stage price problem involving an initial discount, a later fee or tax, and a reverse-percentage question. Label each base, show multipliers, keep money units and rounding explicit, and explain why the order matters. **Independent standard:** correct bases and multipliers; no percentage-point confusion; reverse calculation verified by applying the original change.

## Transfer task

Compare two service offers with different discount rates and fees. Calculate the final amount payable for the same usage, then identify the assumptions that could change the comparison (tax, validity period, hidden fees, limits or different base prices). Explain why the largest advertised discount is not necessarily the best value.

## Entry assumptions and next step

Entry: decimal multiplication/division and fraction-to-decimal conversion. Next: ratios, rates, unit pricing and proportional models. Compound interest and exponential growth are later topics, not assumed here.
