# ATHENA Integrated Project Bank — Batch 02
**Status:** Draft project specifications; adapt to learner age, resources and supervision.
**Purpose:** Produce evidence of transfer across multiple disciplines. Projects are not merely portfolio decoration.

## IP-013 — Build a tiny inventory and sales system
**Disciplines:** ENG, BIZ, FIN, MATH, WORK, COMM
**Deliverable:** A working local prototype or spreadsheet that records stock, sales, cost, contribution margin and exceptions.
**Execution:** Model entities; implement calculations; test edge cases; document assumptions; explain limits.
**Acceptance criteria:** Correct reconciliation, test coverage, readable workflow, honest unit economics and a short demo.
**Evidence:** Preserve artefact, process notes, test results, learner explanation and reflection on what transferred.
**Review:** Reassess after a delay or in a changed context; revise the project if evidence exposes a gap.
