## Non-negotiable status rules
- `AUTHORED_DRAFT` means written, not verified.
- `INTERNALLY_CHECKED` means selected structural and content checks were run.
- `SOURCE_CHECKED` means exact resource sections were inspected.
- `EXPERT_REVIEWED` requires an independent qualified reviewer.
- `LEARNER_VALIDATED` requires actual learner use and recorded results.
- `APPROVED` requires all required gates; never inferred from file count.

No discipline may be declared complete because it has a macro map, baseline records, or a few teaching units.
