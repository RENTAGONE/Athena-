## Planned 20-message production principle

The 20-message target is a production budget, not a completion guarantee. Each message should deliver substantial checked artifacts. If a discipline cannot honestly pass its review gates within the budget, it remains in progress rather than being falsely marked complete.

## Status policy

Authored draft, internally checked, source checked, expert reviewed, learner validated and approved are separate states. External review cannot be self-certified. Scope counts and file counts are never substituted for demonstrated instructional completeness.
