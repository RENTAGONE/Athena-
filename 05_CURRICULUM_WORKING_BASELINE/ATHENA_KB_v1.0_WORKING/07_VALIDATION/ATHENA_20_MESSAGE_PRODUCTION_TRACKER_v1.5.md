## Completion semantics

A discipline cannot be called complete because it has a macro-map, skill-family list, topic outline, one teaching unit or a resource link. Completion requires defensible scope, progression, substantive instruction, aligned assessment/evidence, practical/transfer opportunities, safety/ethics/accessibility review, verified sources, learner-pilot evidence and stable schema/import tests.
