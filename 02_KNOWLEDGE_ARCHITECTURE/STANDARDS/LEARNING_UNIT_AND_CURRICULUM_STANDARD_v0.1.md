# Learning Unit and Curriculum Standard v0.1
Status: Draft.

A learning unit is a coherent instructional package, not a fixed-duration calendar slot. It connects observable objectives, concepts, skills, practice, resources, assessments and completion criteria.

## Required design
1. State the purpose and target learner/context.
2. List measurable objectives using the objective standard.
3. Link only necessary concepts and skill records.
4. State prerequisites and distinguish required from recommended.
5. Provide an instructional sequence with rationale, not arbitrary chapter order.
6. Include retrieval, deliberate practice and application appropriate to the objective.
7. Attach resources with provenance and quality notes.
8. Define an assessment and explicit success criteria.
9. State expected effort as an estimate/range, never a promise.
10. Include adaptation paths for prior competence, gaps, accessibility and available tools.

## Curriculum behaviour
Curriculum is a set of navigable paths, not one universal linear track. Support parallel learning lanes and learner-specific placement. A baseline diagnostic routes the learner; it is not a gate. Completion of a resource or unit does not automatically confer competency. Units can be revised without erasing learner evidence.
